# Front-end presentation and readability

Use a ranger standing against the actual reserve as the main visual. Keep roster left, character center and match/ready actions right. Hosting and joining show separate named fields, a single primary action and concrete connection guidance. The interface has only working game controls; no mock store, progression, ranks or currency.

Palette: slate #12212D, fog #899C9B, pine #29483D, ice #94D6F0, parchment #EDF1E8, amber #D7B779. ReserveSerif carries the Pinefall identity and page titles; ReserveSans carries controls, labels and longer copy. Reuse the combat HUD's translucent surfaces and original pictograms.

Text boxes must reserve actual font line height. Long copy uses measured scroll content rather than character-count guesses. Key-binding rows must stay clear of footer buttons. Player names are bounded; roster lists scroll through twenty participants. Map labels have collision placement and stable styles, with full details on hover.

Verify native 1600×900 and 1280×720 windows with --layout-audit 1, inspect every panel and all handbook tabs, and test long names. Do not accept a successful capture marker as proof of legibility or use headless black captures for review.
