# Unreal 0.3.1 traversal checkpoint

October 29, 2026. Unreal 5.6.1, Development Editor build 14 succeeded. Source/config fingerprints and exact runs are in verification.json. Art/world assets are unchanged from the 0.3 checkpoint.

- **movement-delayed.json:** 24 assertions in two actual processes, 80 ms artificial delay per sender. Actual owning input drives slow crouch versus fast slide, momentum carry, repeated takeoffs/landings, substantial hop gains, release/menu/hunger behavior, a blocked ceiling, host-to-client slide presentation, teleport/water reset hooks and buffered air-crouch landing. Eleven accepted server takeoffs reached 2,400 cm/s during the chain fixture.
- **movement-rendered.json / slide.png:** the same 24 checks passed with an actual rendered client at 1600x900, without injected delay. The capture shows the owned sliding stance, readable one-line hint and shared elevated collision floor. Collision positions, geometry and initial posture are fixtures; movement/jump/crouch requests use normal owning input. No graphics-enabled-host frame-rate claim.
- **combat.json:** sixteen actual player collision/aim/current-cover/headshot checks under 80 ms delay per sender. **reserve.json:** 32 real-owner stock/privacy/vehicle/service/boat/drop/crouch checks. **world.json:** fifteen collision/water/survival checks. **round.json:** 36 assertions in three processes. **wildlife.json:** fifteen assertions plus wrapper verification of three remote skeletal species. **scoped-fire.json:** five ordinary remote target/aiming-fire checks. These ran on the same final native build.

The test setup waits for client possession and acknowledges each synchronized placement before advancing. Both peers must stand on the same static collision geometry. Earlier development attempts caught unreplicated movable-base relative corrections, missing post-travel geometry and input/placement ordering; those failed artifacts are not represented as passing evidence here. Direct accepted-takeoff counts avoid missing very short landings between timer samples.

Actual slide rendering was reviewed. A separate 720p menu view was reviewed locally; its connection-address display is not archived. The scrollable menu remains first-pass UI, and lower control text was not a separate screenshot gate. Walking footstep events are suppressed while sliding, but tests used -nosound and do not certify the audible mix. Repository validation passed with the existing legacy large-stag-clip advisory.

Limits: the slide reuses the planted crouch pose rather than a dedicated production animation. Broader uneven terrain/ledge/moving-platform handling, high-speed airborne gunfight stress, loss/jitter/WAN, twenty-human sessions, rendered FPS, physical microphones and packaged distribution were not validated. The full Unity feature set remains migration work.
