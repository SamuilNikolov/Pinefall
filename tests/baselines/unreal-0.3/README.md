# Unreal 0.3 reserve checkpoint

October 29, 2026. Unreal 5.6.1, Development Editor build 26 succeeded. This is a playable migration checkpoint, not full Unity parity, finished production art or a packaged standalone release.

- **reserve.json:** 32 assertions in two real processes on the 2,016 m reserve. Real owning-client entry/throttle/steering, menu while moving, fuel/service-kit consumption, safe exits, water navigation, occupied-boat destruction, inventory drop/pickup, map privacy, no client duplicate stock, actual cabin capsule doorway/wall collision, remote crouch/uncrouch and visible head lowering on the host. Fixtures arrange positions and stock; this does not certify every road, building, shoreline or slope.
- **combat.json:** sixteen actual player checks at 80 ms artificial lag per sender, including both shooting roles against moving targets, standing/crouched, FP/TP, cover and headshot. Final run used the refreshed stylized character, native gameplay build 24. Build 26 only bounds map text to measured label size; no combat change followed this run. No general WAN/jitter/loss or death-order fairness claim.
- **world.json:** fifteen tree/rock/water/swimming/oxygen/drowning checks. **round.json:** 36 assertions across three processes. **wildlife.json:** fifteen assertions plus three wrapper-verified remote skeletal species. **scoped-fire.json:** five real remote target/aiming-fire checks. These shared-system regressions ran on build 21 before the last grip-only asset changes; final reserve/combat reruns cover the refreshed player geometry and crouch.
- **character.png, crouch.png, characterpistol.png:** actual 1600x900 renders of the active textured stylized ranger. The cramped crouch is replaced with a shallower planted-foot pose and matching collision/camera height. Weapon support-hand contact still needs art polish. No first-person arms or proper magazine/bolt animation yet.
- **map.png:** actual 1280x720 view after measured label bounds were added. The 2K atlas is a terrain/layout bake, not an orthographic screenshot. **village.png:** actual reserve view after road/rock instancing materials were corrected. **truck.png, boat.png, loot.png:** earlier actual first-pass model views from this sweep; these are source/model review, not proof of final art or sound. The truck/boat captures predate later road/rock appearance corrections.

Character source preparation, seventeen-clip refresh, explicit material assignment, reserve generation and atlas bake/import succeeded. Verification JSON records source/content fingerprints. Repository validation passes with the existing large legacy stag-clip advisory. Previous checkpoints remain unchanged.

Limits: no rendered-FPS/hardware comparison, audible sound mix, physical microphone, twenty-human session, public-internet or packaged-distribution validation. Vehicles are first-pass single-seat kinematic models without final engine audio/suspension/passengers. Terrain, foliage, settlement variety, grip quality and biome ecology remain below the final requested visual target. Building/editing, advanced mobility and the full Unity feature set remain migration work; see Design/UNREAL-STATUS.md.
